# 🎥 Live Object Detection & Tracing App

A real-time object detection and tracking web app built using:

- Streamlit
- YOLOv8
- OpenCV
- streamlit-webrtc

The app uses your webcam to detect and track objects live in the browser.

---

# 🚀 Features

✅ Real-time object detection  
✅ Object tracking with YOLOv8  
✅ Live webcam streaming  
✅ Fast and lightweight  
✅ Browser-based interface  

---
